# CreatorHQ Recording Manager (client-side)

Authors: NotHeartYT, Praveen_God_67, Nebrion_Verse

Client-only Fabric mod, Minecraft 1.21.11. Works on any server where you are OP; nothing is installed server-side.

Build (Java 21):
    gradle wrapper --gradle-version 8.14     # once, creates gradlew
    gradlew build
Jar: build/libs/Fabric.CreatorHQ.Recording.1.21.11.jar

Commands: /creatorhq (Hub) | /creatorhq tp <group> [player]
Keys: K = Hub, L = add player under crosshair to active group (both rebindable).
Operator (OP) is required.
